# Changelog

## v0.3.2 - 2026-05-27

- Mark `IsingSolvers.jl` as a legacy package that is no longer recommended for
  new work.
- Document migration paths to maintained QUBO ecosystem solvers.
- Add compatibility with `QUBODrivers` 0.4 and raise the Julia compatibility
  floor to 1.10.
- Update CI to test Julia 1.10 and the latest stable Julia release.
